# TSHEAD(1)

(English version is [here](tshead.man.en.md))

## 名前

tshead - タイムスタンプ対応版"head"コマンド

## 書式

```sh:
tshead [options] -d    duration      [file ...]   … (a)
tshead [options] -xd   duration      [file ...]   … (b)
tshead [options] -d   -duration      [file ...]   … (c)
tshead [options] -xd  -duration      [file ...]   … (d)
tshead [options] -t    date-and-time [file ...]   … (e)
tshead [options] -xt   date-and-time [file ...]   … (f)
```

## 説明

head(1)が与えられたファイルの先頭から指定した*行数*だけを切り出すのに対し、本コマンドは与えられたfileの中の各行の行頭（第1フィールド）にあるタイムスタンプを見て、ある基準となる*時刻*以前の行だけを先頭から切り出します。タイムスタンプ文字列の直後には半角空白<0x20>または水平タブ<0x09>が1文字置かれていなければならず、これがタイムスタンプとそれ以降のフィールドとの区切りと見なされます。なお、[tscat(1)](tscat.man.ja.md)とは異なり、出力時にタイムスタンプ部分が取り除かれることはありません。行の中身には一切手を加えず、通過させるかどうかだけを判定します。本コマンドには姉妹コマンド[tstail(1)](tstail.man.ja.md)があり、そちらは「最終行」を固定点として、ある基準時刻以降の行を末尾から切り出します。

例えば次のようなデータ（access.log）があるとします。

```text:access.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

これに対して`tshead -t 20260821190002 access.log`を実行すると、先頭行から基準時刻（20260821190002）までの行だけが次のように出力されます。

```text:
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
```

基準時刻は、`-d`（先頭行や最終行の時刻からの相対時間）または`-t`（絶対時刻）のいずれかのオプションで指定します。指定方法によって、出力される範囲は次の6パターンのいずれかになります。

* (a) `[ 先頭行, 先頭行の時刻+duration ]`
* (b) `[ 先頭行, 先頭行の時刻+duration )`
* (c) `[ 先頭行, 最終行の時刻-duration ]`
* (d) `[ 先頭行, 最終行の時刻-duration )`
* (e) `[ 先頭行, date-and-time ]`
* (f) `[ 先頭行, date-and-time )`

（`[`・`]`は範囲の端点を含むこと、`(`・`)`は含まないことを示します。）それぞれの詳しい意味は、[「モード」](#モード)セクションを参照してください。

2つ以上のfileが指定された場合、それらはcat(1)のように1つの連結されたストリームと見なされます。したがって、パターン(c)・(d)における「最終行」は最後に指定されたfileの最終行を意味し、いずれかのfileの途中で基準時刻を超える行が現れた時点で、以降のfile（まだ開いていないもの）も含めて処理全体を打ち切ります。

## 引数の説明

### file

データ源となるファイル。省略したり`-`を指定した場合には標準入力と見なされます。複数指定することも可能です。

なお、fileが通常のファイル（レギュラーファイル）である場合には内部的にメモリマップ（mmap）を用いて高速に処理されます。パイプや端末など、シーク不可能な特殊ファイルの場合には、行単位で逐次読み込みながら処理されます。

## オプション

### -c, -e, -I, -z

タイムスタンプ文字列（第1フィールド）および`-t`オプションの引数がどのフォーマットで記録されているとみなすかを指定するオプションです。`-c`、`-e`、`-I`、`-z`はそれぞれ、カレンダー日時、UNIX時間、拡張ISO 8601形式、データ作成開始時刻からの経過秒数を意味し、互いに排他的です。いずれも指定されなかった場合は`-c`が指定されたものと見なします。以下に、それぞれのオプションにおけるフォーマットの詳細を記します。

* -c: カレンダー日時
  * `YYYYMMDDhhmmss[.ddddddddd]`
* -e: UNIX時間
  * `[+|-]n[.ddddddddd]`
* -I: 拡張ISO 8601形式
  * `YYYY-MM-DDThh:mm:ss[,ddddddddd]{+|-}hh:mm`
  * `YYYY-MM-DDThh:mm:ss[,ddddddddd]Z`
* -z: データ作成開始時刻からの経過秒数
  * `[+|-]n[.ddddddddd]`

*YYYYMMDDhhmmss*は年月日時分秒を並べた14桁の整数、*n*はUTCタイムゾーンにおける1970-01-01T00:00:00からの経過秒数（-eの場合）またはデータ作成開始時刻からの経過秒数（-zの場合）を意味します。いずれの場合も、秒未満の時刻を示すために最大9桁の小数部（*ddddddddd*）を付けることができます。

`-z`の経過秒数の起点（「0」が何を意味するか）は、本コマンド自身の起動時刻とは無関係です。あくまで、そのタイムスタンプ付データを作成した側が独自に定義した、何らかの基準時刻からの経過秒数として扱われます。

`-c`指定時の14桁整数値や、`-I`指定時にタイムゾーンを省略した場合の解釈は、OSに設定されているタイムゾーンに依存します。明示的にタイムゾーンを指定したい場合には、環境変数TZを設定するか`-u`オプションを使ってください。

### -d *duration*

出力する範囲の終端となる基準時刻を、時間の長さ（デュレーション）で指定するオプションです。`-t`との併用はできません。

*duration*は次の書式で指定します。

* `A[.B][u]`
  * "A"は整数部です。
  * "B"は小数部で、省略可能です。
  * "u"は単位で、"s"（秒。省略時のデフォルト）・"ms"（ミリ秒）・"us"（マイクロ秒）・"ns"（ナノ秒）・"m"（分）・"h"（時）・"d"（日）のいずれかを指定できます。

*duration*の先頭に"-"を付けるかどうかで、基準時刻の計算方法が変わります。詳しくは[「モード」](#モード)セクションを参照してください。

### -t *date-and-time*

出力する範囲の終端となる基準時刻を、時刻そのもので指定するオプションです。`-d`との併用はできません。

*date-and-time*の書式は、`-c`・`-e`・`-I`・`-z`のどれを指定しているかによって変わります（[「-c, -e, -I, -z」](#-c--e--i--z)を参照）。

### -x

`-d`または`-t`と組み合わせて使う追加オプションです。範囲の終端（基準時刻ちょうどの行）を出力対象から除外します。

`-x`を`-d`または`-t`の直後に融合させたトークン（"-dx"や"-tx"）は指定できません。詳しくは[「バグ」](#バグ)セクションを参照してください。"-xd"・"-xt"のように`-x`を先に置くか、"-d -x"のように分けて指定してください。

### -q

2つ以上のファイルが指定された場合に標準で表示される`==> ファイル名 <==`という見出し行の表示を抑制します。

### -u

タイムゾーンをUTCに設定します。これは環境変数TZに`UTC0`を設定する場合と同じです。`-c`オプション指定時の第1フィールドの解釈や、`-t`オプションの引数の解釈に影響します。

### -Z

パターン(a)・(b)（`-d`の引数に"-"を付けない場合）でのみ意味を持つオプションです。このパターンにおける基準時刻は通常「先頭行のタイムスタンプ」+*duration*ですが、`-Z`を指定すると「時刻0」+*duration*に変わります。

「時刻0」が何を指すかは、[`-c`・`-e`・`-I`・`-z`](#-c--e--i--z)のどれを指定しているかによって異なります。

* `-c`・`-e`・`-I`のいずれかの場合: UNIXエポック（1970-01-01T00:00:00 UTC）
* `-z`の場合: `-z`形式のデータが基準とする、データ作成開始時刻そのもの（UNIXエポックとは無関係です）

パターン(a)・(b)以外（最終行基準のパターン(c)・(d)、`-t`による絶対時刻指定のパターン(e)・(f)）では、`-Z`を指定しても何の効果もありません（エラーにも警告にもならず、単に無視されます）。

## モード

本コマンドは、`-d`オプションと`-t`オプションのどちらを指定するかによって二つのモードで動作します。いずれか一方は必ず指定してください。

### デュレーションモード（-d duration）

`-d`オプションで起動した場合のモードです。*duration*として与えた時間の長さから、範囲の終端となる基準時刻を計算します。

*duration*の先頭に"-"を付けたかどうかにより、基準時刻の計算方法が変わります。

* "-"を付けない場合（パターン(a)・(b)）
  * 基準時刻は「先頭行のタイムスタンプ」+*duration*です。（[`-Z`](#-z)オプション指定時は「時刻0」+*duration*）
  * `-x`オプション省略時（パターン(a)）: `[ 先頭行, 基準時刻 ]` の範囲を出力（基準時刻ちょうどの行を含む）
  * `-x`オプション指定時（パターン(b)）: `[ 先頭行, 基準時刻 )` の範囲を出力（基準時刻ちょうどの行を除く）
* "-"を付けた場合（パターン(c)・(d)）
  * 基準時刻は「最終行のタイムスタンプ」-*duration*です。2つ以上のファイルが指定された場合、「最終行」は最後に指定されたファイルの最終行を意味します。
  * `-x`オプション省略時（パターン(c)）: `[ 先頭行, 基準時刻 ]` の範囲を出力
  * `-x`オプション指定時（パターン(d)）: `[ 先頭行, 基準時刻 )` の範囲を出力

### 絶対時刻モード（-t date-and-time）

`-t`オプションで起動した場合のモードです。*date-and-time*として与えた時刻そのものが、範囲の終端となる基準時刻になります。

* `-x`オプション省略時（パターン(e)）: `[ 先頭行, 基準時刻 ]` の範囲を出力
* `-x`オプション指定時（パターン(f)）: `[ 先頭行, 基準時刻 )` の範囲を出力

## 戻り値

指定されたすべてのファイルを正常に処理できた場合にのみ0を戻します。引数・オプションが不正であった場合、ファイルが開けなかった場合、またはタイムスタンプの解釈に失敗した行があった場合には0以外を戻します。

## 使用例

`access.log`の中から、ある時刻までのアクセス記録だけを取り出す。

```sh:
$ tshead -t 20260821190002 access.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
```

蓄積済みのログファイルから、直近2秒間（まだ変化している可能性がある部分）を除いた、確定済みの部分だけを取り出す。

```sh:
$ tshead -d -2s access.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
```

1行目のタイムスタンプを基準にして、そこから3秒以内の行だけを取り出す。

```sh:
$ tshead -d 3s access.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
20260821190003 request 4
```

`-z`形式のログ（1行目が必ずしも経過秒数"0"とは限らない）に対して、ストリーム中の先頭行ではなくデータ作成開始時刻そのものを基準にして、そこから12秒以内の行だけを取り出す。

```text:uz.log
5 line-at-5
10 line-at-10
15 line-at-15
```

```sh:
$ tshead -z -Z -d 12s uz.log
5 line-at-5
10 line-at-10
```

2つ以上のファイルを指定すると、head(1)と同様にファイル名の見出しが付く。抑制するには`-q`を指定する。

```sh:
$ tshead -t 20260821190004 access1.log access2.log
==> access1.log <==
20260821190000 request 1
20260821190001 request 2

==> access2.log <==
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
$ tshead -q -t 20260821190004 access1.log access2.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

## バグ

`-x`を`-d`や`-t`の直後に融合させたトークン（"-dx"や"-tx"）は指定できません。これは、`-d`・`-t`が引数を必須とするオプションであるため、OSのgetopt()の仕様上、融合させた"x"の部分がその引数の一部（例えば"-dx"なら"-d"の引数として文字列"x"）として解釈されてしまうためです。"-xd"・"-xt"のように`-x`を先に置くか、"-d -x"のように分けて指定してください。

不正な形式のタイムスタンプを持つ行に遭遇すると、警告を表示してその時点で処理全体を打ち切ります。[tscat(1)](tscat.man.ja.md)のように、該当行だけを読み飛ばして後続の行の処理を継続することはありません。

## 規格への準拠

このコマンドのソースコードはC99、IEEE Std 1003.1-2008（“POSIX.1”）に準拠させてあります。
