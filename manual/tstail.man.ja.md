# TSTAIL(1)

(English version is [here](tstail.man.en.md))

## 名前

tstail - タイムスタンプ対応版"tail"コマンド

## 書式

```sh:
tstail [options] -d    duration      [file ...]   … (a)
tstail [options] -xd   duration      [file ...]   … (b)
tstail [options] -d   -duration      [file ...]   … (c)
tstail [options] -xd  -duration      [file ...]   … (d)
tstail [options] -t    date-and-time [file ...]   … (e)
tstail [options] -xt   date-and-time [file ...]   … (f)
```

## 説明

tail(1)が与えられたファイルの末尾から指定した*行数*だけを切り出すのに対し、本コマンドは与えられたfileの中の各行の行頭（第1フィールド）にあるタイムスタンプを見て、ある基準となる*時刻*以降の行だけを末尾から切り出します。タイムスタンプ文字列の直後には半角空白<0x20>または水平タブ<0x09>が1文字置かれていなければならず、これがタイムスタンプとそれ以降のフィールドとの区切りと見なされます。なお、[tscat(1)](tscat.man.ja.md)とは異なり、出力時にタイムスタンプ部分が取り除かれることはありません。行の中身には一切手を加えず、通過させるかどうかだけを判定します。本コマンドは[tshead(1)](tshead.man.ja.md)の姉妹コマンドであり、tsheadが「先頭行」を固定点とするのに対し、本コマンドは「最終行」を固定点とします。

例えば次のようなデータ（access.log）があるとします。

```text:access.log
20260821190000 request 1
20260821190001 request 2
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

これに対して`tstail -t 20260821190002 access.log`を実行すると、基準時刻（20260821190002）から最終行までの行だけが次のように出力されます。

```text:
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

基準時刻は、`-d`（起動時刻や先頭行時刻からの相対時間）または`-t`（絶対時刻）のいずれかのオプションで指定します。指定方法によって、出力される範囲は次の6パターンのいずれかになります。

* (a) `[ 起動時刻-duration, 最終行 ]`
* (b) `( 起動時刻-duration, 最終行 ]`
* (c) `[ 先頭行の時刻+duration, 最終行 ]`
* (d) `( 先頭行の時刻+duration, 最終行 ]`
* (e) `[ date-and-time, 最終行 ]`
* (f) `( date-and-time, 最終行 ]`

（`[`・`]`は範囲の端点を含むこと、`(`・`)`は含まないことを示します。）それぞれの詳しい意味は、[「モード」](#モード)セクションを参照してください。

2つ以上のfileが指定された場合、それらはcat(1)のように1つの連結されたストリームと見なされます。したがって、パターン(c)・(d)における「先頭行」は最初に指定されたfileの1行目を意味し、「最終行」は最後に指定されたfileの最終行を意味します。本コマンドは末尾に指定されたfileから逆順に処理し、いずれかのfileの中で基準時刻より前の行が現れた時点で、それより前に指定されたfile（まだ開いていないもの）は一切開かずに処理を打ち切ります。

## 制限事項

本コマンドは末尾から遡って処理する性質上、tshead(1)には無い次のような制限があります。

### `tail -f`との併用について

出力する範囲の終端は常に「最終行」であるため、本コマンドは入力の終端（EOF）に達するまでは一切出力できません。これはパターン(a)・(b)（基準時刻自体はコマンド起動と同時に確定する）であっても変わりません。したがって、`tail -f`のように終わりのないストリームと組み合わせて使うことはできません（そのような用途には代わりに[tshead(1)](tshead.man.ja.md)を使ってください）。

### メモリ使用量について

fileが通常のファイル（レギュラーファイル）である場合には内部的にメモリマップ（mmap）を用いて末尾から高速に処理されるため、メモリ使用量は問題になりません。

パイプや端末など、シーク不可能な特殊ファイルの場合には、行単位で逐次読み込みながら処理されます。この際、基準時刻が確定済みであれば、基準時刻より前の行はその場で読み捨てられるため、メモリ使用量は実際に出力される範囲程度に抑えられます。ただし、[`-Z`](#-z)オプションを指定した場合（基準時刻が最終行に依存するパターン(a)・(b)）に限り、最終行が判明するまでどの行を保持すべきか判断できないため、入力の終端に達するまで全ての行をメモリ上に保持し続けます。この場合、シーク不可能な入力のサイズに比例してメモリ使用量が増大する点に注意してください。

## 引数の説明

### file

データ源となるファイル。省略したり`-`を指定した場合には標準入力と見なされます。複数指定することも可能です。

## オプション

### -c, -e, -I, -z

タイムスタンプ文字列（第1フィールド）および`-t`オプションの引数がどのフォーマットで記録されているとみなすかを指定するオプションです。`-c`、`-e`、`-I`、`-z`はそれぞれ、カレンダー日時、UNIX時間、拡張ISO 8601形式、本コマンドが起動してからの経過秒数を意味し、互いに排他的です。いずれも指定されなかった場合は`-c`が指定されたものと見なします。以下に、それぞれのオプションにおけるフォーマットの詳細を記します。

* -c: カレンダー日時
  * `YYYYMMDDhhmmss[.ddddddddd]`
* -e: UNIX時間
  * `[+|-]n[.ddddddddd]`
* -I: 拡張ISO 8601形式
  * `YYYY-MM-DDThh:mm:ss[,ddddddddd]{+|-}hh:mm`
  * `YYYY-MM-DDThh:mm:ss[,ddddddddd]Z`
* -z: 本コマンドが起動してからの経過秒数
  * `[+|-]n[.ddddddddd]`

*YYYYMMDDhhmmss*は年月日時分秒を並べた14桁の整数、*n*はUTCタイムゾーンにおける1970-01-01T00:00:00からの経過秒数（-eの場合）または本コマンドの起動時刻からの経過秒数（-zの場合）を意味します。いずれの場合も、秒未満の時刻を示すために最大9桁の小数部（*ddddddddd*）を付けることができます。

`-c`指定時の14桁整数値や、`-I`指定時にタイムゾーンを省略した場合の解釈は、OSに設定されているタイムゾーンに依存します。明示的にタイムゾーンを指定したい場合には、環境変数TZを設定するか`-u`オプションを使ってください。

### -d *duration*

出力する範囲の始端となる基準時刻を、時間の長さ（デュレーション）で指定するオプションです。`-t`との併用はできません。

*duration*は次の書式で指定します。

* `A[.B][u]`
  * "A"は整数部です。
  * "B"は小数部で、省略可能です。
  * "u"は単位で、"s"（秒。省略時のデフォルト）・"ms"（ミリ秒）・"us"（マイクロ秒）・"ns"（ナノ秒）・"m"（分）・"h"（時）・"d"（日）のいずれかを指定できます。

*duration*の先頭に"-"を付けるかどうかで、基準時刻の計算方法が変わります。詳しくは[「モード」](#モード)セクションを参照してください。

### -t *date-and-time*

出力する範囲の始端となる基準時刻を、時刻そのもので指定するオプションです。`-d`との併用はできません。

*date-and-time*の書式は、`-c`・`-e`・`-I`・`-z`のどれを指定しているかによって変わります（[「-c, -e, -I, -z」](#-c--e--i--z)を参照）。

### -x

`-d`または`-t`と組み合わせて使う追加オプションです。範囲の始端（基準時刻ちょうどの行）を出力対象から除外します。

`-x`を`-d`または`-t`の直後に融合させたトークン（"-dx"や"-tx"）は指定できません。詳しくは[「バグ」](#バグ)セクションを参照してください。"-xd"・"-xt"のように`-x`を先に置くか、"-d -x"のように分けて指定してください。

### -q

2つ以上のファイルが指定された場合に標準で表示される`==> ファイル名 <==`という見出し行の表示を抑制します。

### -u

タイムゾーンをUTCに設定します。これは環境変数TZに`UTC0`を設定する場合と同じです。`-c`オプション指定時の第1フィールドの解釈や、`-t`オプションの引数の解釈に影響します。

### -Z

基準時刻の計算方法を変更します。

`-Z`を指定しない場合、パターン(a)・(b)（`-d`の引数に"-"を付けない場合）における基準時刻は「本コマンドが起動した時刻」-*duration*ですが、`-Z`を指定すると「最終行のタイムスタンプ」-*duration*に変わります。

起動時刻を基準にする方法は、実行するたびに結果が変わってしまいます（壁時計に依存し再現性が無いため）。一方、`-Z`を指定して最終行のタイムスタンプを基準にする方法は、同じfileに対して常に同じ結果が得られます（再現性があります）。

なお、このオプションはパターン(a)・(b)でのみ意味を持ちます。パターン(c)・(d)（先頭行基準）やパターン(e)・(f)（`-t`による絶対時刻指定）には影響しません。

## モード

本コマンドは、`-d`オプションと`-t`オプションのどちらを指定するかによって二つのモードで動作します。いずれか一方は必ず指定してください。

### デュレーションモード（-d duration）

`-d`オプションで起動した場合のモードです。*duration*として与えた時間の長さから、範囲の始端となる基準時刻を計算します。

*duration*の先頭に"-"を付けたかどうかにより、基準時刻の計算方法が変わります。

* "-"を付けない場合（パターン(a)・(b)）
  * 基準時刻は「本コマンドが起動した時刻」-*duration*です。（[`-Z`](#-z)オプション指定時は「最終行のタイムスタンプ」-*duration*）
  * `-x`オプション省略時（パターン(a)）: `[ 基準時刻, 最終行 ]` の範囲を出力（基準時刻ちょうどの行を含む）
  * `-x`オプション指定時（パターン(b)）: `( 基準時刻, 最終行 ]` の範囲を出力（基準時刻ちょうどの行を除く）
* "-"を付けた場合（パターン(c)・(d)）
  * 基準時刻は「先頭行のタイムスタンプ」+*duration*です。2つ以上のファイルが指定された場合、「先頭行」は最初に指定されたファイルの1行目を意味します。
  * `-x`オプション省略時（パターン(c)）: `[ 基準時刻, 最終行 ]` の範囲を出力
  * `-x`オプション指定時（パターン(d)）: `( 基準時刻, 最終行 ]` の範囲を出力

### 絶対時刻モード（-t date-and-time）

`-t`オプションで起動した場合のモードです。*date-and-time*として与えた時刻そのものが、範囲の始端となる基準時刻になります。

* `-x`オプション省略時（パターン(e)）: `[ 基準時刻, 最終行 ]` の範囲を出力
* `-x`オプション指定時（パターン(f)）: `( 基準時刻, 最終行 ]` の範囲を出力

## 戻り値

指定されたすべてのファイルを正常に処理できた場合にのみ0を戻します。引数・オプションが不正であった場合、ファイルが開けなかった場合、またはタイムスタンプの解釈に失敗した行があった場合には0以外を戻します。

## 使用例

`access.log`の中から、ある時刻以降のアクセス記録だけを取り出す。

```sh:
$ tstail -t 20260821190002 access.log
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

蓄積済みのログファイルから、末尾直近2秒間だけを取り出す（再現性のある結果が必要なので`-Z`を使用）。

```sh:
$ tstail -Z -d 2s access.log
20260821190003 request 4
20260821190004 request 5
```

先頭行のタイムスタンプを基準にして、そこから2秒経過した時点以降の行だけを取り出す。

```sh:
$ tstail -d -2s access.log
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

2つ以上のファイルを指定すると、tail(1)と同様にファイル名の見出しが付く。抑制するには`-q`を指定する。

```sh:
$ tstail -t 20260821190002 access1.log access2.log
==> access1.log <==

==> access2.log <==
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
$ tstail -q -t 20260821190002 access1.log access2.log
20260821190002 request 3
20260821190003 request 4
20260821190004 request 5
```

（`access1.log`は基準時刻より前の行しか持たないため、見出しは表示されますが中身は空になります。）

## バグ

`-x`を`-d`や`-t`の直後に融合させたトークン（"-dx"や"-tx"）は指定できません。これは、`-d`・`-t`が引数を必須とするオプションであるため、OSのgetopt()の仕様上、融合させた"x"の部分がその引数の一部（例えば"-dx"なら"-d"の引数として文字列"x"）として解釈されてしまうためです。"-xd"・"-xt"のように`-x`を先に置くか、"-d -x"のように分けて指定してください。

不正な形式のタイムスタンプを持つ行に遭遇すると、警告を表示してその時点で処理全体を打ち切ります。[tscat(1)](tscat.man.ja.md)のように、該当行だけを読み飛ばして後続の行の処理を継続することはありません。

なお、本コマンドは末尾から遡って処理するため、不正な行より基準時刻に近い側（末尾側）の行は既に判定済みであれば出力されますが、不正な行より基準時刻から遠い側（先頭側）の行は判定されず出力されません。これは[tshead(1)](tshead.man.ja.md)の「不正な行より末尾側は判定されない」という制約と対称的な関係にあります。
