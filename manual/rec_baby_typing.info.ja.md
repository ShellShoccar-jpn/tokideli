# 赤ちゃんの初タイピングを記録・再生する方法（typeliner & linets & tscatコマンドチュートリアル）

(English version is [here](rec_baby_typing.info.en.md))

成長していくこどもを見守るのは楽しいもの。でも、今の姿が見られるのは今だけですから、こどもの日々の様子を写真や動画に残したいものです。ハッカーにとってみれば、我が子が初めてキーボードに触れた時、どんな文字をどんな風に打ち込むのかということを記録に残し、後で見返すことができたら、きっと楽しいことでしょう。そんなハッカーの皆さんに、赤ちゃんがタイピングした内容を、タイミングも含めて記録・再生する方法をお知らせしたいと思います。

## 用意するもの

* 赤ちゃん（生後半年くらい以降）
* POSIX互換OSの入ったパソコン（Cプログラムのビルドができるもの）
* tokideli（このソフト）

## 準備

上記のものが用意できましたか？「赤ちゃんがいない」という人は職場の人や親戚から借りてきましょう。あるいは、その人達のいるところへパソコンを持って押しかけましょう。

それらが揃ったら、次はターミナルを開いてtokideliをインストールしてください。インストール方法は、[README](../README.ja.md)に書いてあるのでそれに従ってください。

インストールが済んで、tokideliコマンドが使えるようになったら、まずはあなたがタイピング記録の動作テストをしてみましょう。本番で失敗しないように、周到な準備は何事においても大切です。

次のワンライナーを打ち込み、続けてキーボードから`hello,⏎world!⏎`と打ち、最後に[Ctrl]+[D]を押してみてください。

```
$ typeliner -e | linets -3I > test_typing.log
hello,⏎
world!⏎ ←（最後に[Ctrl]+[D]を押す）
$ 
```

各コマンドのオプションの意味を解説します。

* [typeliner(1)](typeliner.man.ja.md)コマンド
  * -eオプション：タイプされた文字をエコーバックしてターミナル画面にも表示する
* [linets(1)](linets.man.ja.md)コマンド
  * -3オプション：タイムスタンプの精度をミリ秒に設定する
  * -Iオプション：タイムスタンプのフォーマットを拡張ISO 8601形式にする

これで、タイプした内容と、タイミングがミリ秒精度で記録されました。本コマンドはもっと高精度に記録できますが、ホームビデオがせいぜい60fpsであることを踏まえればこれで十分でしょう。

では、再生してみましょう。次のワンライナーを打ち込んでください。

```
$ tscat -yIZ test_typing.log
hello,  ←（打ち込んだ内容が、）
world!  ←（同じタイミングで表示される）
$ 
```

オプションの意味は次の通りです。

* [tscat(1)](tscat.man.ja.md)コマンド
  * -Iオプション：拡張ISO 8601形式のタイムスタンプを受け入れる
  * -yオプション：入力されたタイムスタンプ付文字列1つずつに改行を付けずに出力（つまり[typeliner(1)](typeliner.man.ja.md)の入力内容を忠実に復元する）
  * -Zオプション：入力されたファイルの最初の文字列に振られたタイムスタンプを基準にして、以降の文字列の出力タイミングを決める

-Zオプションは最も重要ですので忘れないでください。これがないと、記録されたタイムスタンプの日時に出力しようとしますが、当然それらはすべて過去の日時ですから、すなわちすべての文字が一瞬で出力されてしまいます。

どうでしょうか、自分の打ち込んだ"hello, world!"は打ち込んだとおりのタイミングで表示されましたか？うまくいったら本番に進みましょう！

## 本番

では本番です。赤ちゃんをキーボードの前に連れて来ましょう。そして、次のように本番記録用のファイル名を指定してワンライナーを打ち込み、赤ちゃんにキーボードをバンバン打たせてあげましょう。赤ちゃんのほとぼりが冷めたら[Ctrl]+[D]を押して、レコーディングを終了してください。

```
$ typeliner -e | linets -3I > baby_typing.log
（赤ちゃんにバンバン打ち込ませて、最後に[Ctrl]+[D]を押す）
$ 
```

これで、赤ちゃんが元気よく打ち込んだタイピングの記録がbaby_typing.logに残されたはずです。再生してみましょう！

```
$ tscat -yIZ baby_typing.log
（ここに、赤ちゃんの打ち込んだタイプが当時のタイミングで表示される）
$ 
```
なお、私もレコーディングしました。このドキュメントの最後にそのデータを貼ってありますので、次のワンライナーを打ち込んで再生してみてください。

```
$ cat /PATH/TO/TOKIDELI/manual/rec_baby_typing.info.ja.md | sed -n '/BEGIN_BABY_TYPING/,/END_BABY_TYPING/{/^[0-9]/p;}' | tscat -yIZ
```
